## §1. Инфраструктура (v1 §1–§2 + `roll_one_of` из v2)

Три таблицы, серверные, **НЕ в `SYNC_MODELS`** — как весь мессенджер: ачивки живут
только на сервере, офлайн не роллятся и не выдаются.

```text
Achievement       id, title, description, icon, hidden, rarity
UserAchievement   user_id + achievement_id (составной ключ), unlocked_at
EasterEggLog      user_id, egg_id, triggered_at   — против повторов
```

`server/app/easter_eggs.py`:

- `roll(egg_id, user_id, db)` — шанс СЕРВЕРНЫЙ (клиент не подкрутит через devtools),
  кулдаун сутки на пару «человек + пасхалка».
- `roll_one_of([...])` — перебирает в случайном порядке и возвращает ПЕРВУЮ
  сработавшую. Нужен там, где на одной странице конкурируют несколько (дневник, 404).

Эндпоинты: `GET /web/achievements`, `GET /web/me/achievements`,
`POST /web/easter-eggs/roll`. Выдача ачивки — только изнутри серверной логики,
отдельной ручки «дай мне ачивку» с фронта НЕ будет (иначе их накрутят curl'ом).

Страница «Достижения» в профиле: сетка карточек, закрытые серым «???», открытые
цветные с датой. Тост при получении.

⚠️ **Все ассеты — ленивые.** Мы только что уронили бандл с 1 355 396 до 286 658 байт;
папка пасхалок весит **~6 МБ** (офис 1.85 МБ, референс ULTRAKILL 1.14 МБ, гифка
Hotline 904 КБ, звук ~1.6 МБ). Ни один из них не имеет права попасть в основной чанк:
только `defineAsyncComponent` + отдельные файлы, картинки — в WebP.

## §2. Пасхалки — как я их понял

Ниже — итог после наложения v2 и записок. Где источники расходятся — помечено ❓ и
вынесено в §В.

**1. Дерево Делтарун** · смена любой вкладки · 1/66 (было 1/666, снижено 23.08.2026:
при 666 дерево не выпадало практически никому)
Оверлей поверх страницы, **без роутинга** (адрес не меняется — значит и подсмотреть
нечего, и напрямую не зайти). Чёрный фон, гифка дерева `tree-deltarune.gif`, курсор —
красная душа, играет `tree.ogg`. Клик по ОСНОВАНИЮ СТВОЛА → диалог посимвольно:
«(Он за деревом.)» → «(Он предлагает тебе что-то.)» → «(Вы получили "Яйцо")» →
«(Ну, здесь теперь нет мужчины.)» → «(Это дерево.)». Ачивка — за яйцо.
Ушёл, не взяв → в следующий раз диалог с начала. Ачивка уже есть → сразу последняя
строка. Перезагрузка страницы убирает дерево.

**2. Торт Portal** · день рождения · без шанса
Новое поле `birthday` у пользователя, задаёт админ. Раз в сутки. Вектор с тортом →
[ОК] закрывает. Задуть свечу до [ОК] → Вектор исчезает, остаётся «Торт — это ложь» +
ачивка. ❓ассетов нет вовсе, ❓поле — это ПДн, см. §В5.

**3. Undertale «Решимость»** · кнопка сохранения · 1/100
Тост снизу-справа пиксельным шрифтом + короткий retro-chime.

**4. Papers Please** · открытие ЛЮБОГО профиля (своего и чужого)
Штамп в углу. Два готовых: «ВЪЕЗД РАЗРЕШИТЬ» и «ВО ВЪЕЗДЕ ОТКАЗАТЬ». Для
заблокированного/отчисленного — красный отказ ДЕТЕРМИНИРОВАННО, не по шансу.

**5. Isaac, кубик D6** · страница оценок · 1/500
Кубик рядом с оценками, клик → оценки визуально подменяются иконками предметов (20
спрайтов готовы), при наведении — настоящий балл. Только клиентский стейт, в БД ничего.

**6. Dark Souls** · выход из аккаунта · по шансу
Вместо обычного прощания — экран темнеет сильнее, анимация меча, золотом «СЕССИЯ
ЗАВЕРШЕНА», ачивка. ⚠️ Ачивка и отзыв токена — В ОДНОЙ транзакции.

**7. G-Man** · только «Настройки» · 1/200
Без анимации. Из `artworks-*.jpg` делаю PNG с прозрачностью: чёрное вырезано, остаются
белые части. Появляется еле заметно, чем дольше сидишь во вкладке — тем чётче (но
остаётся полупрозрачным), на пороге страница моргает чёрным → лицо исчезает → через
пару секунд ачивка. ❓про моргание см. §В6.

**8. Cyberpunk** · после успешного входа · 1/77
Секунда глитча + глитч-SFX (нужно найти со свободной лицензией) → фраза Джонни
(`Джонни-Сильверхенд-*.mp3`) ОДНОВРЕМЕННО с `guitar.MP3`; гитара нарастает с нуля и
затухает в конце, без обрыва. Ачивка после входа.

**9. Detroit, LED** · вход в аккаунт · ~1/100, студенты и преподаватели
Кольцо LED **вместо кружка статуса в левом нижнем углу** (это `SidebarUserPanel`).
Цвет от оценок/статистики. Появилось — дали ачивку. ❓см. §В1.

**10. Страница 404** · всегда обычная, поверх неё ~10% → одна из двух
`roll_one_of(['rdr2_404','stanley_parable_404'])`.
**RDR2:** бумага + силуэт ковбоя, «…у меня есть ПЛАН… ЕЩЁ ОДНА СЕССИЯ!» (ассетов нет —
делаю вёрсткой).
**Stanley:** случайная озвучка из 7 готовых файлов (три разных текста), титрами внизу
синхронно, и **цифра 404 на странице меняется на 427** — отсылка к самой игре.

**11. ULTRAKILL** · верх журнала
Счётчик стиля 1:1 с референсом: полупрозрачная плашка под наклоном, сверху «ULTRAKILL»,
полоска, ниже строки в духе «+ПЯТЁРКА», «+ПОСЕЩАЕМОСТЬ», ниже MULTIPLIER, ниже FRESH.
❓триггер завязан на успеваемость, см. §В1.

**12. DOOM** · аватарка
Долгов нет → золотое свечение. Есть → однократная красная вспышка рамки на секунду.
Крови и синяков на лице нет никогда. ❓см. §В1.

**13. Disco Elysium** · двойка в дневнике · 1/80, ТОЛЬКО владельцу
Кружок у двойки, наведение → окно skill-check. Чистый клиент, не сохраняется. ❓§В1.

**14. Hotline Miami** · выход из беседы (1/89) и вход в «Сообщения» (1/89)
По записке: неоновый жёлто-розовый фильтр на пару секунд → снизу выезжает чёрная
полоса, сбоку — переливающийся четырёхугольник с головой Вектора. Пока не выехало —
не скипается. Клик → появляется текст. Клик → уезжает, через пару секунд ачивка.
Текст A: «Чувак, эта беседа просто отстой. Мне не интересны эти люди.»
Текст B: «Тебе действительно нравится писать людям сообщения, не так ли?»
Силуэт слева из плана — игнорирую, как сказано. ❓сторона, см. §В4.

**15. FNAF** · вход в аккаунт · 1/87 И время 00:00–06:00
По записке: вход бросает **не в журнал, а в офис** (картинка готова). Клик по ноутбуку
→ журнал, и внизу журнала появляется полупрозрачная кнопка «обратно в офис».
Цикл из плана: иногда Вектора нет — он невидим И в шторке, И в отдельной вкладке;
60 секунд; задал вопрос → вернулся, цикл сброшен; ничего не сделал → мягкое «буп» из
дверного проёма (справа на картинке он есть). Никаких скримеров. ❓см. §В3.

**16. Skyrim** · ≥3 неудачных входа подряд, ЗАТЕМ успешный · 30%
После успешного входа: экран гаснет на секунду, кадр повозки + «Эй, ты. Наконец-то ты
очнулся…», дальше обычный дашборд. Реальное сообщение об ошибке не подменяется.

**17. Far Cry 3** · 8 неудачных попыток подряд · 10%
Готовое аудио Вааса, под полем ввода — субтитры построчно, синхронно со звуком.
Срабатывает на самой неудаче, успех не нужен. 🔴 **Сейчас недостижимо, см. §В2.**

## §В. Решения Влада (22.08.2026) — вопросы закрыты

**Кто вообще видит пасхалки.** ТОЛЬКО студенты. Преподаватель и админ не видят ни
одной. Но ачивки, которые студент выставил у себя в профиле, они видят — значит
ачивка это ещё и публичный элемент профиля, а не только личный список.

**Привязка к успеваемости — оставлена, но у каждой своя:**

- **ULTRAKILL** — только у отличников.
- **DOOM** — состояние аватарки зависит от оценок, градиентом от двойки до пятёрки
  (а не «долги/нет долгов», как было в плане).
- **Disco Elysium** — встречается при ЛЮБОМ балле, не только у двойки; держать надо
  не оценку, а стиль речи — как в игре, через внутренние голоса и skill-check.
- **Detroit** — может выпасть у каждого, цвет кольца меняется по ситуации.

**Far Cry** — «сделай так, чтобы сработало». Условие 8 неудач упирается в
`throttle.MAX_FAILS = 7`, поэтому вешаю на СЕДЬМУЮ — последнюю, которую человек
реально видит перед блокировкой.

**FNAF** — офис это ОТДЕЛЬНАЯ ВКЛАДКА после входа. Ноутбук открывает привычный журнал,
внизу журнала — полупрозрачная кнопка выхода в офис (как в игре). Кнопки «пропустить»
НЕ делаем: пасхалка только у студентов, а журнал и так работает. При «скримере»
текущая вкладка сворачивается, мы оказываемся в офисе, и Вектор говорит «БУ».

**G-Man** — уточнено: картинка появляется почти прозрачной и с каждой секундой
становится отчётливее; в какой-то момент экран моргает чёрным ОДИН раз; ачивку дают
через 2 секунды после этого. (Не «моргает в течение двух секунд» — я понял неверно.)

**Hotline Miami** — делать по РЕФЕРЕНСУ, в тексте записки могли быть опечатки. Кадр
разбираю на составляющие и собираю ту же композицию из НАШИХ ассетов: чёрная полоса
снизу с моноширинным текстом, справа наклонённый переливающийся четырёхугольник с
головой Вектора.

**Portal** — админ указывает только МЕСЯЦ И ЧИСЛО, без года. Спрайтов нет, готовлю
заглушки до того, как нарисует Арина.

**Ассеты — не трогать, оставить как есть.** Это отсылки, а не продающая фича:
Deltarune — музыка и дерево временные (Тоби Фокс не даёт прав на музыку, Арина
нарисует похожее дерево позже, пока заглушка ради узнаваемости); арт G-Man, спрайты
Isaac, штампы Papers Please — тоже отсылки; озвучка сделана нейросетью. Вопрос прав
решается позже с юристом. **Из этого следует: пока НЕ пережимаю и не подменяю их
своими — только оптимизирую вес там, где это не меняет картинку.**

**`isaac/images.jpg`** — попал случайно, Влад удалил.

## §Г. Что будет сделано помимо самих пасхалок

- **Миграции:** три новые таблицы `create_all` заведёт сам; поле `birthday` — это
  НОВАЯ КОЛОНКА в существующей таблице, значит идемпотентный `ALTER` в `db.py` плюс
  регрессия в `test_db_migrations.py` (иначе на бою её просто не будет).
- **Сторож на «шанс только на сервере»**: структурный тест, что ни один компонент
  пасхалок не зовёт `Math.random()` для решения «показывать или нет».
- **Сторож на вес бандла**: проверка, что ассеты пасхалок не попали в основной чанк.
- **CSP не трогаем** — всё своё, с нашего же домена.
- **`EasterEggLog` растёт** — добавлю в `retention.py` уборку записей старше полугода
  (там уже есть уборка надгробий и уведомлений, это её же класс).
- **CLAUDE.md и `docs/HISTORY.md`** — запись по итогам.

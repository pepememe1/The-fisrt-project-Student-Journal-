# Озвучка «Вектора» (TTS) — план развития

Статус на 2026-07-23. Что уже живёт — в коде (`server/app/tts_service.py`, `web/src/stores/tts.js`,
`vector/tts.py`). Здесь — куда двигаемся дальше: выразительный голос на боевом GPU-сервере и
хорошая офлайн-озвучка на десктопе. Плюс честные заметки по лицензиям и ElevenLabs.

## 0. Что есть сейчас (демо-VPS, CPU)

- Движок — **Silero v4_ru** (torch CPU) на VPS, синтез на хосте, WAV → Web Audio API в браузере.
- Голоса: `eugene` (муж), `baya` (жен). Просодия SSML: темп `medium`, паузы `<break>` на
  точках/запятых, тон мужского чуть выше.
- Ограничение: Silero — быстрая, но **малоэмоциональная** модель. Это её потолок, не баг.
  Демо тянет; «вау» будет только на другой модели + GPU.

## 1. ⚠️ Лицензия Silero — проверить ДО продажи

Silero раздаёт часть моделей бесплатно, но у них есть Enterprise-трек, и бесплатные веса
могут быть **non-commercial**. Для продаваемого продукта (44-ФЗ) это надо закрыть:
- либо подтвердить право на коммерческое использование конкретной модели (`v4_ru`),
- либо заменить на заведомо пермиссивную (см. §2, Piper — MIT).

Пока не подтверждено — считать Silero временным демо-движком.

## 2. Боевой GPU-сервер (i3-12100F + RTX 3060 12 ГБ) — выбор модели

Синтез уже вынесен на хост (эндпоинт `/web/vector/tts`), так что смена движка — **серверная,
клиента не трогает**. Нужно только: (а) выбрать модель, (б) сделать движок выбираемым конфигом
(`tts_engine`), (в) реализовать выбранный бэкенд по образцу `tts_service`.

| Кандидат | Качество | Лицензия | Русский | Вывод |
|---|---|---|---|---|
| **Piper** | среднее+, живее Silero | **MIT** ✅ | да (denis/ruslan/irina) | безопасный дефолт для продажи |
| **XTTS v2 (Coqui)** | высокое, эмоц., клонирование | **non-commercial** ⚠️ | да | только если очистим лицензию |
| **Клон своего голоса** | высокое, уникальный голос | наша (запись с согласия) | да | «как ElevenLabs», но права наши |
| Silero v4 | среднее | под вопросом (§1) | да | текущий демо-движок |

**РЕШЕНИЕ (Ярослав, 2026-07-23): цель — КЛОН СВОЕГО голоса.** Уникальный голос Вектора с
чистыми правами, выразительный как ElevenLabs, но наш.

⚠️ **Юридический нюанс по клон-моделям (важно, не наступить):**
- **XTTS v2** — лучший zero-shot клонер, но лицензия **CPML = non-commercial**. Для продажи НЕ
  годится, если не купим/не очистим права. Не брать по умолчанию.
- **OpenVoice v2 (MyShell)** — **MIT** ✅, zero-shot клонирование тембра поверх базового TTS
  (MeloTTS). Надо проверить качество РУССКОГО (база MeloTTS RU бывает средней).
- **Обучить СВОЙ голос (Piper/VITS/GlowTTS)** — **MIT/чисто**, голос полностью наш. Не zero-shot:
  нужен датасет (30–60+ мин чистой записи) и обучение на GPU, зато ноль сомнений в правах. Для
  продаваемого продукта — самый безопасный «клон».

**Итог по выбору движка:** для боевого продукта склоняемся к **обучению своего голоса** (чисто),
zero-shot (OpenVoice, если РУ-качество ок) — как быстрый прототип. XTTS — только для внутренних
проб, не в прод.

### Что записывать (можно начинать СЕЙЧАС, не дожидаясь GPU-сервера)
Долгий пункт — не код, а запись. Спека:
- **Диктор:** один человек, с письменным согласием на клонирование/коммерческое использование
  голоса (это и есть «права наши»). Тембр под Вектора — дружелюбный, не грубый.
- **Тех: ** тихая комната без эха, один и тот же микрофон, **WAV 22–24 кГц, моно, 16 бит**, без
  музыки/шумоподавления «на максимум» (портит голос).
- **Объём:** для zero-shot (OpenVoice) — 3–5 мин; для ОБУЧЕНИЯ своего голоса — **30–60 мин и больше**,
  разбитые на короткие фразы (5–15 с) с текстовой расшифровкой каждой.
- **Содержание:** разнообразный русский — вопросы, перечисления, числа/оценки («средний балл
  четыре и две десятых»), приветствия. Чем ближе к тому, что реально говорит Вектор, тем лучше.

**Код уже готов принять клон:** движок переключается конфигом `tts_engine`; реестр
`tts_service._RENDERERS` — добавить бэкенд `clone` с сигнатурой `(text, voice) -> wav-байты`,
и synthesize/кэш/SSML/эндпоинт менять НЕ придётся. На GPU: `device="cuda"`, прогрев при старте.

## 3. Офлайн-десктоп — RHVoice

Идея Влада «прога ставит голос в винду» — делается ЧИСТО через **RHVoice** (открытый, LGPL,
хорошие русские голоса, ставится как SAPI5-голос Windows, работает офлайн).

- **Код уже готов:** `vector/tts.py::_speak_sapi` теперь ПРЕДПОЧИТАЕТ RHVoice-голоса
  (aleksandr/anton/artemiy — муж, anna/elena/irina/victoria — жен), когда они установлены.
  Ничего не установлено → откат на Microsoft SAPI (Ирина).
- **Что осталось (упаковка):** решить, как ставить RHVoice с прогой:
  - вариант А — установщик десктопа регистрирует RHVoice как системный SAPI-голос (нужны права
    админа; портативный .exe станет инсталлятором);
  - вариант Б — тащить RHVoice рядом с прогой и звать напрямую (без системной установки, портативность
    сохраняется). Предпочтителен для нашего онефайла.
- Голоса RHVoice под разными лицензиями (движок LGPL, часть голосов CC-BY) — брать те, что можно
  распространять коммерчески.

## 4. ElevenLabs — вердикт

«Взять сэмплы EL и чуть изменить, чтоб под АП не попало» — **нельзя**:
- технически из клипов нельзя озвучивать произвольный текст (нужен генератор, не записи);
- юридически ToS EL прямо запрещают использовать их вывод для создания других голосов; «лёгкая
  правка» это не обходит. Для продажи бюджетному учреждению — недопустимый риск.

Легальный аналог того же результата — **клон своего голоса** на GPU (§2). Если очень хочется
именно EL — только официальный платный API server-side для обезличенного текста, но это
иностранная зависимость (блокировки/оптика/цена) и для колледжа как ОСНОВА не годится.
